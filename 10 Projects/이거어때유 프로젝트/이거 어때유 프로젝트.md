# 이거 어때유 프로젝트

---

## 📄 본문
### 이거 어때유
지역상권을 살리자는 취지로 만들게된 대전의 근처 음식점 정보 제공 서비스이다. 근처 음식점 검색 혹은 음식 키워드를 검색해서 위치 기반 지도 검색이 가능하며, 인기 음식 검색어 순위를 제공하는 사용자 편의성을 제공하는게 특징이다.

### 제공하는 기능
- 현재 위치 기반 근처 음식점 검색
- 인기 검색어 순위 제공
- 음식점 리뷰 데이터 제공
- 자주 찾는 음식, 지역 즐겨 찾기

### 담당 역할
- 위치 기반 음식점 조히 기능을 위한 카카오 API 클라이언트 개발
- 인기 검색어 순위 기능 개발
- RestDocs + OAS3 API 명세화 작업
