---

## 📄 본문
### 핏
FiT은 실시간 음성 스트리밍 기술을 활용한 사일런스 컨퍼런스 솔루션이다. 사일런스 문화는 해외에서 유행한지는 오래됐지만, 비교적 국내에서는 최근에 이슈가된 문화이다. 대표적으로 한강공원에 음악을 트는 DJ가 있고 청중은 모두 헤드셋을 착용하고 즐기고 있다. 제 3자가 보기에는 굉장히 조용하지만, 청중들은 모두 같은 음악을 들으며 즐기고 있습니다. 이런 문화를 사일런스 문화라고 한다.

이런 사일런스 문화가 해외에서는 컨퍼런스에 도입이 되었다. 기존 해외의 사일런스 컨퍼런스 사례를 보면 컨퍼런스장에 구비된 헤드셋을 이용하여 발표자의 마이크 음서을 청중들이 듣게되는 형식이다.

저희가 해결하고자 했던 문제는 세션장마다 헤드셋을 구비해야 한다는 점과, 다른 세션을 듣기 위해 헤드셋을 벗고 다시 착용해야 하는 불필요한 과정이었습니다.

이를 해결하기 위해 사용자가 자신의 이어폰이나 헤드셋으로 세션을 청취하고, 마치 오디오 채널을 고르듯 원하는 세션을 자유롭게 선택할 수 있도록 실시간 음성 스트리밍 기술을 적용했습니다.

### 제공하는 기능
- 오디오 스트리밍
- 실시간 Q&A
- 실시간 혼잡도
- 세션 미리담기
- 맞춤 세션 추천

### 담당 역할
- 실시간 음성 스트리밍 기능
- 카카오, 구글, 네이버 소셜 로그인 기능
- JWT 인증 인가 기능
- AWS S3를 이용한 이미지 업로드 및 관리 기능
- 세션 미리담기 기능

### WebRTC 선택 이유
오디오 스트리밍을 웹앱 환경에서 구축하기 위해서 사용하게 되었다. 브라우저 환경에서 화상 채팅이나 음성 통화를 활 때 사용하는 기능으로 1:N 관계의 실시간 스트리밍을 생각하게 되어서 사용했다.

### Kurento 사용 이유
가장 유력한 후보는 mediasoup와 kurento였다. kurento는 업데이트가 안된지 오래된 기술이지만 자바 기반에 API를 제공하는 장점이있었다. PM분께서 공지한 테스트 완료 기간이 1주일이였기에, 빠르게 구축할 수 있는 kurento를 사용했다.
