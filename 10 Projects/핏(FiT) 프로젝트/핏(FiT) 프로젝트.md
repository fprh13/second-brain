# 핏(FiT) 프로젝트

---

## 📄 본문
### 개요
FIT은 **실시간 음성 스트리밍 기술을 활용한 사일런스 컨퍼런스 솔루션**입니다. 사일런스 컨퍼런스란, 발표자의 음성을 모두가 헤드셋으로 청취하여 외부 소음 없이 발표에 집중할 수 있는 형태의 컨퍼런스를 의미합니다. 참가자는 자신의 이어폰이나 헤드셋을 통해 원하는 **세션을 오디오 채널처럼 자유롭게 전환하며 청취**할 수 있습니다. 구름 부트캠프에서 주최한 구름톤에서 **우수상**을 수상하고 구름 프로젝트 쇼케이스에 전시되었습니다.

### 주요기능
실시간 오디오 스트리밍 기능
- 원하는 세션을 청취하고, 언제 어디서나 같은 경험을 제공받도록
실시간 채팅 Q&A
- 부담 없이 강연자에게 질문하고, 소통하도록
실시간 혼잡도 기능
- 혼잡도 높은 장소를 피해 원활한 청취 환경을 누리도록
세션 미리담기 시스템
- 관심 세션을 쉽게 정리해 놓치지 않고 청취하도록
맞춤 세션 추천
- 본인에게 최적화된 세션을 추천받고, 청취하도록

### 담당업무
실시간 음성 스트리밍 기능
카카오, 구글, 네이버 소셜 로그인 기능
JWT 인증 인가 기능
AWS S3를 이용한 이미지 업로드 및 관리 기능
세션 미리담기 기능
