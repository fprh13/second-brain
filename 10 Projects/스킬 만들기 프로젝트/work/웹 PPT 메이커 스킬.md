# 웹 PPT 메이커 스킬

## 개요
- 순수 HTML, CSS, JavaScript 기반 웹 프레젠테이션 제작 스킬을 정리하고 개선하는 작업이다.
- 상위 프로젝트는 [[스킬 만들기 프로젝트]]이며, 이 노트는 해당 프로젝트의 `work` 트랙을 담당한다.
- 초기 목표는 라이브러리 의존 없이 슬라이드 레이아웃, 전환, 네비게이션, 전체화면, 슬라이드 번호 표시를 지원하는 흐름을 만드는 것이다.
- 리서치, 구현 수정, 스킬화, 후속 개선 요청이 하나의 작업 맥락으로 이어졌다.

## 메모

### 목표
- 웹 프레젠테이션 구현 원칙을 정리한다.
- `/ppt-maker` 계열 스킬의 요구사항과 제약을 명확히 남긴다.
- 프롬프트 로그 대신 의사결정과 변경 포인트를 중심으로 기록한다.
### 초기 리서치 범위
- 슬라이드 레이아웃과 DOM 구조
- 키보드, 마우스, 터치 기반 네비게이션
- 슬라이드 전환 애니메이션과 입력 잠금 처리
- 슬라이드 내부 빌드 애니메이션과 speaker notes 처리

#### 실제 프롬프트 보기
```text
순수 HTML, CSS, JavaScript만으로 웹 기반 슬라이드 프레젠테이션을 구현하는 최적의 방법을 리서치하세요.
외부 라이브러리(Reveal.js 등)는 참고만 하고, 최종 구현은 순수 바닐라로 가능해야 합니다.

다음 4개의 주제를 서브에이전트로 병렬 리서치하세요:

## Agent 1: 슬라이드 레이아웃 & DOM 구조
- 슬라이드를 full-viewport로 표시하는 CSS 레이아웃 방법
  (Flexbox, Grid, absolute positioning 비교)
- 슬라이드 컨테이너와 개별 슬라이드의 HTML 구조 설계
- 반응형 슬라이드 구현 방법
  (vw/vh 단위 활용, aspect-ratio 유지)
- 16:9 비율 고정 방법 및 브라우저 호환성

## Agent 2: 키보드 & 마우스 네비게이션
- 키보드 이벤트(<->, Space, PageUp/Down) 처리 방법
- 슬라이드 전환 시 URL hash 동기화(#slide-1 방식)
- 터치/스와이프 제스처 지원 구현(touchstart, touchend)
- 진행 표시바(progress bar) 및 슬라이드 번호 표시 방법

## Agent 3: 슬라이드 전환 애니메이션
- CSS transition vs CSS animation vs Web Animations API 비교
- 대표적인 전환 효과 구현: fade, slide, zoom
- 전환 중 이전/다음 슬라이드를 동시에 보여주는 방법
- GPU 가속 활용법(transform, will-change 속성)
- 애니메이션 도중 추가 입력을 막는 방법(이벤트 잠금)

## Agent 4: 슬라이드 내 콘텐츠 애니메이션(빌드 효과)
- 슬라이드 진입 시 요소를 순서대로 등장시키는 방법(data-step 속성 등)
- CSS class 토글 방식의 appear/reveal 구현
- 코드 블록 하이라이트 표시 방법(특정 줄 강조)
- 화자 노트(speaker notes) 숨김/표시 처리
```

### 구현 수정 요청
- 스크롤 스냅 대신 JS 기반 `fixed + absolute` 전환으로 변경
- 다크/골드 프리미엄 톤으로 색상 재설계
- 콘텐츠 폭을 `1000px`에서 `680px`로 축소
- 한글 본문 폰트를 `Noto Sans KR` 우선으로 조정
- 결과물을 단일 HTML 파일 기준으로 정리

#### 실제 프롬프트 보기
```text
RESEARCH.md와 index.html, script.js, style.css 파일을 읽고
index.html을 아래 4가지 기준으로 수정해줘. 콘텐츠는 그대로 유지.

1. 뷰포트 풀스크린
- 위아래 여백 없이 브라우저 화면을 꽉 채우도록
- 스크롤 스냅 대신 JS fixed + absolute 전환 방식으로 변경

2. 다크/골드 프리미엄 컬러
- 그린 엑센트 -> 골드(#C6A55C) 전면 교체
- 텍스트는 차가운 화이트 대신 따뜻한 아이보리 계열로

3. 콘텐츠 폭 축소
- max-width 1000px -> 680px로 줄이고 내부 컴포넌트도 비율에 맞게 축소

4. 한글 폰트 최적화
- Google Fonts에서 Noto Sans KR 추가(wght 400:700)
- 한글 본문은 Noto Sans KR, 영문/코드는 기존 Inter + JetBrains Mono 유지
- font-family 우선순위: 'Noto Sans KR', 'Inter', sans-serif

결과물은 단일 HTML 파일로 줘.
```

### 후속 조정 사항
- 샘플 페이지를 10개로 구성
- 페이지 이동은 한 페이지 단위로 동작하도록 수정
- 메모에 `선소비`라고 적어 둔 기존 로직을 복구하면서 페이지 이동과 함께 유지하도록 요청
- 최종적으로는 좌우 방향키의 페이지 이동만 한 페이지 단위로 조정
- 진행 상황 바, 이전/다음 버튼, `Notes` UI 제거
- 샘플 페이지 수정 시 한 페이지 이동에서 전체 요소가 모두 보이도록 보정
- `index.html` 구조 점검 후 스킬화 직전 검토 진행

#### 실제 프롬프트 보기
```text
마지막 다듬기:
- 샘플 페이지는 10개로 하고 페이지 이동 시 한 페이지 단위로 이동하게 해줘.

오류 발견:
- 기존 선소비 로직을 다시 복구해줘. 선소비와 페이지 이동 두 개를 동시에 가져가고 싶어.
- 기존 선소비를 복구해줘. <- -> 방향키에 대한 페이지 이동만 한 페이지 단위로 이동하게 해줘.
- 상단의 진행 상황 바, 이전, 다음, Notes를 제거해줘.
- index.html의 샘플 페이지를 수정할 거야. 한 페이지 이동 시에는 전체 페이지 요소를 다 보여줘야 해.

스킬 제작 전 마지막 체크:
- index.html가 잘 구성됐는지 검토하고 수정 진행해줘.
```

### 스킬화
- `$skill-creator`로 순수 HTML, CSS, JavaScript 웹 프레젠테이션 제작 스킬 생성 요청
- 필수 기능은 방향키 이동, `F` 전체화면, 슬라이드 번호 표시
- 참고 자산은 `RESEARCH.md`, `index.html`, `codex-작동원리.md`
- `/ppt-maker` 사용 단계에서 다크 배경, 중앙 정렬 기반 시안 3개 생성 요청
- 이후 `SKILL.md`에 스크립트 줄바꿈 가독성 개선 요구사항 반영
- 마지막으로 단조로움 제거, 제목 줄바꿈 완화, 스크립트에 맞는 애니메이션 구성까지 확장

#### 실제 프롬프트 보기
```text
$skill-creator 순수 HTML, CSS, JavaScript로 웹 프레젠테이션을 만드는 스킬을 생성해줘.

필수 기능:
- 방향키로 슬라이드 넘기기
- F 누르면 전체화면
- 슬라이드 번호 표시

참고:
- @RESEARCH.md
- @index.html

스킬 사용 예시:
- /ppt-maker @codex-작동원리.md
- 우선 시안 3개를 생성해줘
- 다크 배경 스타일
- 콘텐츠는 중앙 스타일

추가 업데이트:
- 스크립트의 줄 바꿈으로 가독성이 떨어지는 부분을 방지해줘
- 스킬 명시가 빠졌던 요청도 다시 반영해서 SKILL.md에 업데이트해줘

대대적인 개편:
1. 단조로운 구성 X, 이모지 사용
2. 중앙 제목은 가로로 넓게 가져가되 너무 길 경우만 줄바꿈
3. 스크립트에 맞는 애니메이션 효과와 그에 맞는 요소 구성 적용
```
