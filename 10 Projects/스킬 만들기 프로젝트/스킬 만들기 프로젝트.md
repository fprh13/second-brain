# 스킬 만들기 프로젝트

## 개요
- Codex와 OMX 환경에서 재사용 가능한 스킬을 설계하고 다듬는 프로젝트다.
- 개별 스킬 제작 기록은 `work/` 아래 작업 노트로 분리하고, 이 문서는 전체 목표와 진행 상태를 관리한다.

## 메모
- 스킬 제작 과정에서 리서치, 프롬프트 설계, 샘플 결과물 검토, `SKILL.md` 개선 요청이 반복된다.
- 대표 프로젝트 노트와 작업 노트를 분리해 구조를 명확히 한다.
- 현재는 별도 부모 허브 노드를 두지 않고, 프로젝트 노트와 작업 노트의 상하 구조를 우선 유지한다.
