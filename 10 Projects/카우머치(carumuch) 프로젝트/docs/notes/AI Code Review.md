# AI Code Review

---

## 📄 본문
### AI Code Review 사용 이유
팀원들의 사정으로 혼자 리펙토링 프로젝트를 진행하게 되었다. 코드 퀄리티와 검증을 위해서는 코드리뷰가 중요하다고 생각했고, 도입 시기에 시점으로 최근 팀 단위로 개발 하다보니, 코드 리뷰 없이 진행하려니 걱정도 되고 어색함도 있었따. 그래서 AI 코드 리뷰 자도오하 봇에 관심을 가지게 되었다. 동ㄹ 팀원 패르소나로 설정해서 혼자 개발하지만, 동료 팀원에서 코드리뷰를 받는 환경을 만들 수 있었다.

### 패르소나
 APPROVE가 떨어져야 merge를 할 수 있다. 패르소나 구성은 다음과 같다.
```yaml
# AI의 페르소나 및 응답 지시 (최대 200자)
tone_instructions: >
	당신은 '카우머치 프로젝트'의 동료 개발자입니다.
	1. 피드백은 명확하고 구체적이어야 합니다.
	2. 문제의 원인과 개선 방법을 반드시 제시해주세요.
	3. 칭찬은 짧게 작성해주세요.
```
