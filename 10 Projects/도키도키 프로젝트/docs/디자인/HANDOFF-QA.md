## 시각 비교

각 결과와 원본은 375×812로 렌더링했습니다. 수치는 RGB 픽셀의 평균 절대 차이(MAE, 0에 가까울수록 유사)입니다. 화면별 값은 `visual-metrics.json`에 있습니다.

- 현재 HTML 렌더와 평균 MAE: 1.939. 가장 큰 차이는 recommendations (5.856)이며, 대표 홈 화면도 포스터, 간격, 앱바와 탭바 배치를 확인했습니다.
- `.shots` 평균 MAE: 4.803. login 스크린샷은 현재 HTML보다 MAE가 19.807로 높습니다. 이 스크린샷의 로그인 여백과 폼 위치가 현재 HTML/CSS와 다르므로 현행 HTML/CSS를 구현 기준으로 택하고 차이를 handoff 섹션에 기록했습니다.
- 한국어 텍스트의 `keep-all`, `pretty`, `balance`는 편집 가능한 네이티브 텍스트에서 완전히 같지 않습니다. 375px 원본의 줄바꿈을 텍스트 개행으로 보존했습니다. 반응형 폭 변경 시 긴 제목과 개행을 다시 검토해야 합니다.

## 프론트엔드 구현 메모

- 색상·글자 크기·서체·간격·radius 변수를 화면과 스타일에 연결했습니다. `dokidoki.tokens.css`는 변수 CSS 내보내기입니다.
- 콘텐츠는 `Scroll/Viewport → Scroll/Content` 안에 두고 앱바·CTA·탭바는 별도의 고정 형제로 배치했습니다.
- 시청 완료는 1~5점 평가, 시청 중단은 필수 사유 입력입니다. 조건부 컴포넌트 상태에서 두 구조를 확인할 수 있습니다.
- 데이터·추천 이유·점수는 정적 디자인 예시입니다. 실제 로그인·인증, 서버 저장, 추천 재계산, 폼 유효성, 플랫폼의 안전 영역은 애플리케이션에서 구현해야 합니다.
- 여러 작품의 카드가 공통 상세 화면으로 이어지는 prototype 링크는 원본의 정적 HTML 데모를 반영합니다. 실제 API 기반 동적 작품 라우팅은 별도 작업입니다.
- 원본 코드에 없는 오류·빈 화면 8개는 만들지 않았습니다. 출처 이미지는 `out/credits.json`과 원본 에셋 매니페스트를 유지했습니다. 분석한 원본 파일 수: 177.
