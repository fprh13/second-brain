# macOS 개발 환경 메모리 경량화

---

## **📄 본문**

### 개요
MacBook Air M2 (8GB RAM) 환경에서 개발 도구의 메모리 점유를 줄이고, 제한된 시스템 자원을 효율적으로 활용하기 위해 기존 도구를 경량 대안으로 교체하였다.

### 개발 도구 변경

| **용도**     | **기존 도구**      | **변경 도구**  |
| ---------- | -------------- | ---------- |
| 데이터베이스 관리  | DataGrip       | Sequel Ace |
| 컨테이너 관리    | Docker Desktop | OrbStack   |
| API 테스트    | Postman        | Yaak       |
| 문서 및 노트 관리 | Notion         | Obsidian   |

### 용도별 변경 사항

#### 데이터베이스 관리: DataGrip → Sequel Ace

- **차이:** JVM 기반의 다목적 데이터베이스 IDE에서 macOS 네이티브 MySQL 클라이언트로 변경
- **이점:** 메모리 사용 부담 감소, 빠르고 간결한 데이터베이스 관리
- **트레이드오프:** 고급 SQL 자동완성, 리팩토링, 실행 계획 시각화 등 일부 기능 축소

#### 컨테이너 관리: Docker Desktop → OrbStack

- **차이:** Docker Desktop의 가상화 환경 대신 macOS에 최적화된 경량 컨테이너 실행 환경 사용
- **이점:** 가상화 오버헤드 및 유휴 리소스 사용 감소, 빠른 실행과 간결한 관리
- **트레이드오프:** Docker Desktop 전용 확장 기능 및 일부 관리 기능 사용 제한

#### API 테스트: Postman → Yaak

- **차이:** Electron 기반의 종합 API 플랫폼에서 Tauri 기반의 간결한 API 클라이언트로 변경
- **이점:** 앱 자체의 리소스 사용 감소 기대, 간결한 UI와 로컬 중심의 API 테스트 환경
- **트레이드오프:** Postman의 고급 협업 및 자동화 기능 일부 대체 어려움

#### 문서 및 노트 관리: Notion → Obsidian

- **차이:** 클라우드 중심의 협업형 문서 도구에서 로컬 Markdown 기반 지식 관리 도구로 변경
- **이점:** 오프라인 작업, Git 기반 버전 관리, 상대적으로 낮은 메모리 사용 부담
- **트레이드오프:** 실시간 공동 편집 및 협업 데이터베이스 기능 제한

### 기대 효과 및 얻은 이점

- **메모리 효율:** 불필요한 백그라운드 프로세스와 애플리케이션 오버헤드 감소
- **개발 성능:** IntelliJ IDEA, Spring Boot, MySQL 등 핵심 개발 프로세스에 더 많은 가용 메모리 확보
- **작업 환경:** 기능이 복잡한 도구 대신 필요한 기능에 집중한 간결한 개발 환경 구성
- **데이터 관리:** 로컬 파일과 Git 중심의 개발 및 문서 관리 워크플로 강화
