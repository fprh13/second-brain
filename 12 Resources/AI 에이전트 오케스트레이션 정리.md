# AI 에이전트 오케스트레이션 정리

## 요약
- 현재 볼트는 사용자가 본문을 먼저 작성하고, AI는 Markdown 정리와 링크 점검을 보조하는 방식으로 운영한다.
- 노트 파일은 요청 없이는 이동하지 않고, 위치가 어색하면 추천만 남긴다.
- 노드 연결은 `관련 노트`를 중심으로 정리하고, 불필요한 교차 링크는 줄인다.
- 템플릿은 본문 중심 구조를 유지하고 불필요한 frontmatter는 사용하지 않는다.

## 본문
### 핵심 규칙
- 본문은 재작성하지 않고 치명적인 오타만 수정한다.
- 기존 `##` 섹션 사이로 내용을 옮기지 않는다.
- 코드, 명령어, 설정, 로그는 code block으로 작성한다.
- 위치 추천은 가능하지만 실제 노트 이동은 사용자가 요청할 때만 수행한다.
- 스크린샷과 일반 첨부만 `attachments/` 아래로 정리할 수 있다.
- 의미 있는 연결은 `관련 노트`로 남긴다.

### 현재 처리 방식
- 운영 정책 문서는 `VAULT_RULES.md`다.
- `README.md`는 저장소 소개 문서다.
- `AGENTS.md`, `AGENT_KOR.md`는 실행 가드레일을 담는다.
- `14 Templates`는 frontmatter 없이 본문과 링크 섹션 중심으로 유지한다.
- 기존 프로젝트 노트와 리소스 노트는 불필요한 metadata를 제거하고 필요한 링크만 남기는 방향으로 정리한다.

### 용어 정리
- 관련 노트: 개념적으로 연결되지만 상하 관계로 고정하기 어려운 노트
- 위치 추천: 더 자연스러운 폴더 경로만 제안하는 작업
- 첨부 정리: 스크린샷, 다이어그램, 일반 파일을 `attachments/` 아래로 정리하는 작업
- 최소 메타데이터: `type`, `tags`, 상태 추적값 같은 frontmatter를 기본적으로 두지 않는 방식

### 메타데이터 메모
- 현재 템플릿은 불필요한 frontmatter를 사용하지 않는다.
- 필요한 정보는 본문 섹션에 직접 적는 편을 우선한다.
- 프로젝트 링크와 참고 링크는 본문이나 `관련 노트` 섹션에서 관리한다.

### 셸 스크립트로 할 수 있는 것
- `scripts/` 아래 스크립트는 여전히 남아 있다.
- 다만 현재 운영 원칙은 파일 이동 금지와 메타데이터 최소화를 우선하므로, 실제 실행 전에는 현재 규칙과 맞는지 먼저 확인해야 한다.
- 특히 이동이나 frontmatter 기록을 자동으로 수행하는 옵션은 지금 기준과 충돌할 수 있다.

### 지금까지 한 작업
- `README.md`를 저장소 소개 문서로 축약했다.
- `VAULT_RULES.md`를 추가해 운영 규칙을 분리했다.
- `AGENTS.md`, `AGENT_KOR.md`를 실행 가드레일 중심으로 정리했다.
- `14 Templates`의 번호 체계와 링크 섹션 구조를 정리했다.
- 불필요해진 `workflow.md`와 `skills/` 문서를 제거했다.

### 검토 결과
- 현재 기준에 맞는 핵심은 본문 보존, 위치 추천, 관련 노트 연결, 첨부 정리다.
- `관련 노트`를 중심으로 그래프 의미를 살리는 편이 현재 기준에 더 맞다.
- 스크립트나 이전 메모를 사용할 때는 현재 규칙과 충돌 여부를 먼저 확인해야 한다.
