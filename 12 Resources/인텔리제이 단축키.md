# 인텔리제이 단축키

## 📄 요약
- macOS 기준 IntelliJ 단축키와 Translation 플러그인 단축키를 모아둔 참고 노트입니다.
- 자주 쓰는 단축키는 아래 메모 섹션에 따로 추려두었습니다.

## 📄 본문
- `command + option + V` : 선택한 표현식을 **변수로 추출(Extract Variable)**
- `command + option + F` : 선택한 값을 **필드로 추출(Extract Field)** → 외부에서 사용할 수 있는 클래스 필드로 빼고 싶을 때 사용
- `option` 두 번 + 위아래 : **멀티 커서 선택** → 같은 위치를 여러 줄에서 동시에 수정 가능
- `command + E` : **최근 열었던 파일 / 클래스 목록** → 이전에 작업하던 클래스로 빠르게 이동
- `command + 1` : **프로젝트 패키지 창 이동** → 패키지에서 `ESC` 누르면 다시 코드 영역으로 이동
- `option + Enter` : **Quick Fix / 추천 기능 실행** → inner class 생성 등 다양한 자동 수정 제안
- inner class를 외부 클래스로 분리할 때
  → `F6` → `command + Enter` : **외부 클래스 파일로 이동(move)**
- `Shift + F6` : **이름 변경 리팩토링 (Rename)** → 변수, 클래스 이름을 변경하면 전체 사용 위치가 함께 변경됨
- `command + O` : **클래스 검색 후 이동** → `command + E`와 같이 사용하면 이전 위치로 돌아가기 편함
- `command + ,` : **IntelliJ Settings 열기**
- `shift + command + 위아래` : **코드 블록을 파일 상단 / 하단으로 이동**
- `shift + option + 위아래` : **현재 줄을 위 / 아래로 이동**
- `F2` : **다음 에러(빨간 줄) 위치로 이동**
- `option + Enter` : **테스트 코드 생성, Quick Fix, 자동 코드 생성 기능 실행** (`tearDown` 등 생성 가능)
- `command + backSpace` : **현재 줄 전체 삭제**

### 번외 플러그인 (Translation 플러그인)
- `control + command + U` : **영어 단어 한국어 의미 검색**
- `control + command + O` : **번역 / 해석 기능 실행**
- `control + command + O` : **한글 설명 입력 → 영어 변수명 추천**
- `command + shift + U` : **소문자, 대문자로 변경**
