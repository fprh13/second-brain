# 🧠 second-brain
개인 지식 관리용 Obsidian Vault입니다.

## 구조
```text
Vault
├─ 00 Inbox
├─ 01 Permanent
├─ 02 MOCs
├─ 10 Projects
├─ 11 Areas
├─ 12 Resources
├─ 13 Archive
├─ 99 Templates
├─ attachments
├─ docs
├─ AGENTS.md
└─ README.md
```

## 폴더 요약
| 폴더             | 역할                 |
| -------------- | ------------------ |
| `00 Inbox`     | 빠른 캡처와 초안          |
| `01 Permanent` | 장기적으로 남길 개념 노트     |
| `02 MOCs`      | 부모 허브 노트           |
| `10 Projects`  | 기간성 작업 기록          |
| `11 Areas`     | 지속 관리 영역           |
| `12 Resources` | 참고 자료 정리           |
| `13 Archive`   | 종료된 정보 보관          |
| `99 Templates` | 노트 템플릿             |
| `attachments`  | 스크린샷, 다이어그램, 일반 파일 |
