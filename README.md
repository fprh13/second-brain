# 🧠 second-brain
개인 지식 관리용 Obsidian Vault입니다.

## 개요
이 볼트는 사용자가 본문을 먼저 작성하고, 구조와 연결은 최소한으로 정리하는 방식을 기준으로 운영합니다.

핵심 방향:
- 사용자가 쓴 내용을 우선 보존
- 파일 위치 결정은 사용자 중심
- 관련 노트가 잘 보이는 연결
- 최소 메타데이터와 읽기 쉬운 Markdown 유지

자세한 운영 규칙은 [VAULT_RULES.md](VAULT_RULES.md)를 참고합니다.

## 구조
```text
Vault
├─ 00 Inbox
├─ 01 Permanent
├─ 02 MOCs
├─ 10 Projects
├─ 11 Areas
├─ 12 Resources
├─ 13 Archive
├─ 14 Templates
├─ attachments
├─ AGENTS.md
├─ AGENT_KOR.md
├─ README.md
└─ VAULT_RULES.md
```

## 폴더 요약
| 폴더             | 역할                 |
| -------------- | ------------------ |
| `00 Inbox`     | 빠른 캡처와 초안          |
| `01 Permanent` | 장기적으로 남길 개념 노트     |
| `02 MOCs`      | 부모 허브 노트           |
| `10 Projects`  | 기간성 작업 기록          |
| `11 Areas`     | 지속 관리 영역           |
| `12 Resources` | 참고 자료 정리           |
| `13 Archive`   | 종료된 정보 보관          |
| `14 Templates` | 노트 템플릿             |
| `attachments`  | 스크린샷, 다이어그램, 일반 파일 |
