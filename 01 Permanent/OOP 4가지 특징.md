# OOP 4가지 특징

---

## 📄 본문
### OOP(객체 지향 프로그래밍)
현실세계의 사물과 같은 객체를 만들고 그 객체에서 필요한 특징을 뽑아서 프로그래밍을 수행하는 방식이다.
객체지향 프로그래밍은 4가지 특징이 있다.
1. 추상화
2. 상속
3. 다형성
4. 캡슐화

#### point
- **추상화**는 하나의 특징을 하나의 개념으로 뽑아내는 것
- **상속**은 부모에 정의된 메서드를 상속받은 자식도 사용하고 필요에 따라 재정의하는 것
- **다형성**은 하나의 타입이나 인터페이스를 통해 여러 객체를 동일한 방식으로 다루면서도, 실제 객체에 따라 서로 다른 동작을 수행할 수 있는 성질
- **캡슐화**는 정보은닉을 통해서 내부에서는 높은 응집도를 가지고 외부에서는 낮은 결합도를 갖게하는 것

##### 객체 지향 프로그래밍 vs 절차 지향 프로그래밍
객체 지향 프로그래밍에서는 데이터와 그 데이터에 대한 행동(메서드)이 하나의 "객체"안에 함께 포함되어 있다.
이러한 객체들 간의 상호작용을 중심으로 프로그래밍 하는 방식이다.
- 무엇이 이 일을 담당해야하지? (What, 무엇을 중심)
절차 지향 프로그래밍은 이름 그대로 절차를 지향하는 방식이다.
데이터를 처리하는 함수와 절차를 중심으로 프로그램을 구성하며, 작업의 처리 과정과 실행 순서를 중요하게 생각한다.
- 이 작업을 어떠한 순서로 처리하지? (How, 어떻게 중심)
##### 객체
현실세계의 사물과 같은 것 "모든 실재하는 대상"을 객체 지향 프로그래밍 언어에서는 객체라고 부른다.

### 추상화
객체지향에서 추상화란 객체의 공통적인 특징이나 핵심 개념을 추출하고, 불필요한 세부 구현은 숨기는 것을 의미한다.
이를 통해 복잡성을 줄이고, 핵심적인 역할과 책임 중심으로 설계 할 수 있다.

#### point
**추상클래스**: 실체인 인트턴스가 존재하지 않는다. 상속을 목적으로 사용된다. 즉 부모 클래스의 역할을 담당하지만, 인스턴스로 생성할 수 없다.

**추상메서드**: 기능 구현을 강제할 때 사용된다. 부모 클래스의 메서드가 추상적인 개념만 나타난다면, 자식 클래스에서 오버라이딩하여 재정의해야한다. 즉, 구현을 강제하는 것 

### 상속
상속은 기존 클래스의 필드와 메서드를 새로운 클래스에서 재사용하기 위해 사용한다.
상속을 사용하려면 "extends" 키워드를 사용해서 진행한다. 다중 상속은 불가능하며, 단일 상속만 가능하다.

#### point
- 상속 관계의 객체를 생성하면 그 내부에는 부모와 자식이 모두 생성된다.
- 현재 타입에서 기능을 찾지 못하면 상위 부모 타입으로 기능을 찾아서 실행한다.

##### 상속 vs 구현
상속은 이름 그대로 부모의 기능을 물려 받는 것이 목적이다.
하지만 인터페이스는 모든 메서드가 추상 메서드이다.
따라서, 물려받을 수 있는 기능이 없고, 오히려 인터페이스에 정의한 모든 메서드를 자식이 오버라이딩 해서 기능을 구현해야한다. 따라서 구현한다고 표현한다.

### 다형성
다형성은 이름 그대로 "다양한 형태"를 뜻한다.
프로그래밍에서 다형성은 한 객체가 여러 타입의 객체로 취급될 수 있는 능력을 뜻한다.
보통 하나의 객체는 하나의 타입으로 고정되어 있는데, 다형성을 사용하면 하나의 객체가 다른 타입으로 사용될 수 있다.

#### point
- 부모타입은 자식타입을 담을 수 있다. 반대로 자식 타입은 부모 타입을 담을 수 없다.
- 반환 타입을 통해서 메모리 참조를 따라간다. Parent poly = new Child();라면 부모를 먼저 확인하기 때문에 자식의 메서드를 사용할 수 없다.

##### 인터페이스
인터페이스는 객체가 제공해야 할 행위를 추상화하여 규약(계약)으로 정의하는 역할을 한다.

구현 클래스는 인터페이스에 정의된 메서드를 구현함으로써 동일한 규약을 따르며, 각 클래스는 해당 메서드의 구체적인 동작을 서로 다르게 구현할 수 있다.

###### 인터페이스 vs  추상클래스
추상클래스는 상속을 위한 것, 즉 부모의 기능을 재활용하기 위해 사용된다.
인터페이스는 모두 같은 동작을 한다라는 보장을 하기 위한 규약으로 사용된다.

### 캡슐화
서로 연관있는 속성과 기능들을 하나의 캡슐로 만들어 데이터를 외부로부터 보호하는 것을 말한다.

#### point
접근제한자:
- **public**은 기능을 숨기지 않고 어디서든 호출할 수 있게 공개한다.
- **default**는 나의 패키지 안으로 속성과 기능을 숨길 때 사용, 외부 패키지에서 해당 기능을 호출할 수 없습니다.
- **protected** 는 상속 관계로 속성과 기능을 숨길 때 사용, 상속 관계가 아닌 곳에서 해당 기능을 호출할 수 없습니다.
- **private**은 나의 클래스 안으로 속성과 기능을 숨길 때 사용, 외부 클래스에서 해당 기능을 호출할 수 없습니다.
