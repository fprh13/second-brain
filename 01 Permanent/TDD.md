# TDD
---

## 📄 본문
TDD는 작은 단위의 테스트 케이스를 작성하고 그에 맞는 코드를 작성하여 테스트를 통과한 후에 상황에 맞게 리팩터링하는 테스트 주도 개발 방식입니다.

TDD는 레드-그린 사이클을 반복하며 진행합니다.

1. Red: 어떤 기능을 검증하는 테스트가 실패하도록 코드를 작성하고 실제로 실패하는지 확인합니다.
2. Green: 해당 기능을 검증하는 테스트가 통과하도록 코드를 작성하고 실제로 성공하는지 확인합니다.
3. Refactor: 앞에 실패하는 테스트와 성공하는 테스트를 모두 검증했다면, 작성한 코드를 깨끗하고 가독성 좋게 고칩니다.
4. Repeat: 이 세 가지 과정을 반복하여 프로그램을 완성합니다.
