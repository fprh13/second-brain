# TCP/IP 4계층
---

## 📄 본문

### TCP/IP 4계층

TCP/IP 4계층은 인터넷에서 실제 데이터 통신을 위해 사용되는 네트워크 모델로, 네트워크 통신 과정을 4개의 계층으로 구분한다.

OSI 7계층이 네트워크 통신 과정을 개념적으로 세분화한 참조 모델이라면, TCP/IP 모델은 실제 인터넷 통신에 사용되는 TCP/IP 프로토콜 체계를 기반으로 구성되어 있다.

OSI 7계층과 TCP/IP 4계층은 다음과 같이 대응할 수 있다.

```
OSI 7계층                    TCP/IP 4계층

7. Application  ┐
8. Presentation ├──────────→ Application
9. Session      ┘

10. Transport    ───────────→ Transport

11. Network      ───────────→ Internet

12. Data Link    ┐
13. Physical     ┘──────────→ Network Interface
```

#### point

##### 4계층 - 응용 계층 (Application)

OSI 모델의 응용 계층, 표현 계층, 세션 계층에 해당하는 기능을 포함한다.

- 애플리케이션이 네트워크 서비스를 이용할 수 있도록 제공
    
- 데이터 표현 및 변환
    
- 통신 세션 관리
    

주요 프로토콜

- HTTP / HTTPS
    
- FTP
    
- SMTP
    
- DNS
    

##### 3계층 - 전송 계층 (Transport)

애플리케이션 프로세스 간 종단 간(End-to-End) 데이터 전송을 담당한다.

- 포트 번호를 이용하여 애플리케이션 프로세스 구분
    
- 데이터 분할 및 재조립
    
- TCP의 경우 신뢰성 있는 데이터 전송 제공
    
- 흐름 제어 및 오류 제어
    

주요 프로토콜

- TCP
    
- UDP
    

##### 2계층 - 인터넷 계층 (Internet)

서로 다른 네트워크 사이에서 패킷을 목적지까지 전달하는 역할을 담당한다.

- IP 주소를 이용한 장치 식별
    
- 목적지 네트워크까지 패킷 전달
    
- 라우터를 통한 라우팅
    

주요 프로토콜

- IP
    
- ICMP
    

> ARP는 IP 주소에 대응하는 MAC 주소를 알아내는 프로토콜이다. TCP/IP 모델에서는 자료에 따라 인터넷 계층 또는 네트워크 인터페이스 계층과 관련된 프로토콜로 분류되기도 한다.

##### 1계층 - 네트워크 인터페이스 계층 (Network Interface)

실제 네트워크를 통해 데이터를 전달하는 역할을 담당한다.

OSI 모델의 데이터 링크 계층과 물리 계층에 해당하는 기능을 포함한다.

- MAC 주소를 이용한 같은 네트워크 구간 내 통신
    
- 프레임 단위 데이터 전송
    
- 데이터를 실제 전기, 광, 무선 신호로 변환하여 전송
    

예시

- Ethernet
    
- Wi-Fi
    

### 실제 데이터 전송 흐름

사용자가 웹 브라우저에서 서버로 HTTP 요청을 전송한다고 가정하면 데이터는 TCP/IP 계층을 따라 아래 방향으로 전달된다.

#### 송신 측 - 캡슐화

```
4계층 - Application
HTTP 요청 데이터 생성
        ↓
3계층 - Transport
TCP Header 추가
→ Segment
        ↓
2계층 - Internet
IP Header 추가
→ Packet
        ↓
1계층 - Network Interface
Ethernet/Wi-Fi 등의 Header 추가
→ Frame
        ↓
실제 네트워크를 통해 Bit 전송
```

각 계층에서는 자신의 역할을 수행하기 위해 필요한 정보를 헤더 등에 추가한다.

```
Application Data
       ↓
TCP Segment
       ↓
IP Packet
       ↓
Frame
       ↓
Bit
```

목적지에서는 반대 순서로 각 계층의 정보를 처리하면서 원래 애플리케이션 데이터를 전달한다.

```
Bit
 ↓
Frame
 ↓
IP Packet
 ↓
TCP Segment
 ↓
Application Data
```

### OSI 7계층과 TCP/IP 4계층의 차이

OSI 7계층과 TCP/IP 4계층은 모두 네트워크 통신 과정을 계층적으로 구분하지만 목적과 구성에서 차이가 있다.

| OSI 7계층                | TCP/IP 4계층                |
| ---------------------- | ------------------------- |
| 네트워크 통신을 설명하기 위한 참조 모델 | 실제 인터넷 프로토콜 체계를 기반으로 한 모델 |
| 7개의 계층으로 세분화           | 4개의 계층으로 구성               |
| 응용, 표현, 세션 계층을 각각 구분   | 응용 계층으로 통합                |
| 데이터 링크, 물리 계층을 각각 구분   | 네트워크 인터페이스 계층으로 통합        |

실제 인터넷 통신은 TCP/IP 프로토콜 체계를 기반으로 동작하지만, 네트워크의 기능이나 문제 발생 위치를 설명할 때는 OSI 7계층 모델도 널리 사용된다.
